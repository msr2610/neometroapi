# मेट्रो API दस्तावेज़ीकरण

## उपलब्ध एंडपॉइंट्स

### 1. GET /metro/hello

**विवरण:** यह एक टेस्ट एंडपॉइंट है जो "helloworld" टेक्स्ट वापस करता है। यह एंडपॉइंट API के काम करने की जाँच के लिए उपयोग किया जाता है।

### 2. GET /metro/lines

**विवरण:** यह एंडपॉइंट सभी मेट्रो लाइनों की जानकारी प्रदान करता है। यदि कोई लाइन नहीं मिलती है, तो यह एक त्रुटि संदेश वापस करेगा।

### 3. GET /metro/lines/linename

**विवरण:** किसी विशिष्ट मेट्रो लाइन की विस्तृत जानकारी प्राप्त करने के लिए इस एंडपॉइंट का उपयोग किया जाता है। लाइन का नाम URL में प्रदान करना होगा।

### 4. GET /metro/lines/linename/stations

**विवरण:** किसी विशेष मेट्रो लाइन पर स्थित सभी स्टेशनों की सूची प्राप्त करने के लिए इस एंडपॉइंट का उपयोग किया जाता है।

### 5. GET /metro/lines/linename/interconnections

**विवरण:** किसी विशेष मेट्रो लाइन से जुड़ी हुई अन्य लाइनों की जानकारी प्राप्त करने के लिए इस एंडपॉइंट का उपयोग किया जाता है।

### 6. GET /metro/lines/linename/status

**विवरण:** किसी विशेष मेट्रो लाइन की वर्तमान स्थिति (सक्रिय है या नहीं) जानने के लिए इस एंडपॉइंट का उपयोग किया जाता है।

### 7. GET /metro/stations/stationName/status

**विवरण:** किसी विशेष मेट्रो स्टेशन की वर्तमान स्थिति जानने के लिए इस एंडपॉइंट का उपयोग किया जाता है। यह स्टेशन की ID, नाम और सक्रियता स्थिति प्रदान करता है।

### 8. GET /metro/stations/stationName/lines

**विवरण:** किसी विशेष स्टेशन से होकर गुजरने वाली सभी मेट्रो लाइनों की जानकारी प्राप्त करने के लिए इस एंडपॉइंट का उपयोग किया जाता है।

### 9. GET /metro/route

**विवरण:** दो स्टेशनों के बीच का सबसे उपयुक्त मार्ग खोजने के लिए इस एंडपॉइंट का उपयोग किया जाता है। इसमें प्रारंभिक स्टेशन ('from') और अंतिम स्टेशन ('to') के नाम क्वेरी पैरामीटर के रूप में प्रदान करने होंगे।
